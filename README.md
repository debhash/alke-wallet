## 📖 Descripción

**Alke Wallet** es un proyecto de billetera digital desarrollado como ejercicio práctico de JavaScript utilizando **jQuery** y **Bootstrap**.

Originalmente, la aplicación estaba compuesta por múltiples archivos HTML. Posteriormente, decidi simplificar su estructura y transformarla en una **Single Page Application (SPA)** muy básica, con el objetivo de ejemplificar el manejo del **DOM**, la navegación entre vistas y la interacción dinámica con los elementos de la página sin necesidad de recargarla.

## 🚀 Tecnologías utilizadas

- HTML5
- Bootstrap 5
- JavaScript (ES6+)
- jQuery

## 🎯 Objetivos del proyecto

- Practicar los fundamentos de JavaScript.
- Comprender el funcionamiento del DOM.
- Manipular elementos dinámicamente mediante jQuery.
- Implementar una SPA sencilla sin frameworks.
- Organizar y reutilizar componentes de la interfaz.
- Simular las funcionalidades básicas de una billetera digital.
